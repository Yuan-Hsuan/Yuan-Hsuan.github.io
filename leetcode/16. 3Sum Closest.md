## 🎙️ Naive Solution
The naive solution is to explore all possible triplets using three nested loops, which takes $O(N^3)$ time. To optimize this, we need a way to make our search directional rather than brute-force.

## 🚀 Pitch

### The Bottleneck Observation
The brute-force search wastes effort because it treats the array as unordered — with no sense of whether a triplet's sum is too big or too small, it has to try every triplet. 
However, **once the array is sorted, the sum becomes directional.** 

### The Strategy: Sorting + Two Pointers
By sorting the array first in $O(N \log N)$ time, we can apply the Two-Pointer technique. This allows us to fix one number and find the other two numbers in linear time, reducing the overall time complexity to $O(N^2)$.

### The Precise Execution
I iterate through the sorted array with an explore pointer `i`. For the subarray to the right of `i`, I set `left = i + 1` and `right = n - 1`. At each step I compute the sum of the three elements and track the smallest `|current_sum - target|` seen so far, updating my global `closest_sum`.

**Directional adjustment** (this is what sorting buys us):
- `current_sum < target` → move `left` right to **increase** the sum.
- `current_sum > target` → move `right` left to **decrease** the sum.
- `current_sum == target` → return immediately; the distance is 0, the best possible.

**Complexity**
- **Time — $O(N^2)$:** sorting is $O(N \log N)$; the fixed-pointer + two-pointer traversal is $O(N^2)$, which dominates.
- **Space — $O(1)$ ~ $O(\log N)$:** The extra space for our two-pointer logic is strictly $O(1)$. However, since we are using the standard sorting function, the underlying (IntroSort) algorithm will take $O(\log N)$ space on the call stack due to recursion. Therefore, the overall space complexity is $O(\log N)$.

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
public:
    int threeSumClosest(vector<int>& nums, int target) {
        
        int n = nums.size();
        if (n < 3) return -1;

        sort(nums.begin(), nums.end());
        
        int res = 0;
        int diff = INT_MAX;
        
        for (int i = 0; i < n-2; i++) {
            int left = i+1;
            int right = n-1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                int new_diff = 0;
                if (sum > target) {
                    new_diff = sum - target;
                    right--;
                } else if (sum < target) {
                    new_diff = target - sum;
                    left++;
                } else {
                    return target;
                }

                if (new_diff < diff) {
                    res = sum;
                    diff = new_diff;
                }
            }
        }

        return res;
    }
};
```
