## 🎙️ Naive Solution
The naive approach is to find the maximum height to the left and right for every single bar in the array. The water trapped above any bar `i` is determined by `min(max_left, max_right) - height[i]`. Doing this scanning for each element results in an O(N^2) time complexity, which is highly inefficient.

## 🚀 Pitch (雙指針 O(1) 空間優化口條)

### The Bottleneck Observation

The monotonic stack solution is efficient, but it requires O(N) auxiliary space. To optimize this to O(1) space, we must reuse the bottleneck principles from the "Container With Most Water". The water trapped at any single position is strictly bounded by `min(max_left, max_right) - current_height`.

### The Strategy: Two-Pointer Convergence

We can place two pointers, `left` at the beginning and `right` at the end, while maintaining two variables: `max_left` and `max_right`.
Instead of scanning the whole array to find boundaries for each bar, we compare `height[left]` and `height[right]`. Whichever side is lower acts as our guaranteed bottleneck. If `height[left] < height[right]`, the right side is mathematically guaranteed to be tall enough to support a reservoir, meaning the left position's water level depends *only* on its own historical peak (`max_left`).

### The Precise Execution

We iterate until the pointers meet. If `height[left] < height[right]`, we update `max_left`. If the current `height[left]` is less than `max_left`, it forms a pocket, and we add `max_left - height[left]` to our total. Then we move `left++`. We apply the identical, symmetric logic to the right side if `height[right] <= height[left]`. This achieves O(N) time and O(1) space seamlessly.


**Complexity**
- **Time — O(N):** the two pointers converge in a single pass over `height`.
- **Space — O(1):** only `max_left`, `max_right`, and two pointers; the input is read-only.

## 🛠️ Optimization (最優化 C++ 程式碼)

這是在實務生產環境與外商面試中，最完美、最具可讀性的 $O(1)$ 空間解法：

```cpp
class Solution {
public:
    int trap(const vector<int>& height) {
        // 🛡️ 防禦性編程：處理極端邊界
        if (height.empty()) return 0;

        int left = 0;
        int right = height.size() - 1;
        
        int max_left = 0;
        int max_right = 0;
        int total_water = 0;

        while (left < right) {
            // 🌟 核心貪婪選擇：矮的那一側是 bottleneck，優先處理
            if (height[left] < height[right]) {
                if (height[left] >= max_left) {
                    max_left = height[left]; // 更新歷史最高牆，此時無法集水
                } else {
                    total_water += max_left - height[left]; // 歷史牆比當前高，形成凹槽
                }
                left++;
            } else {
                if (height[right] >= max_right) {
                    max_right = height[right];
                } else {
                    total_water += max_right - height[right];
                }
                right--;
            }
        }

        return total_water;
    }
};

```

## 🛡️ Defensive Coding (防禦性與面試官加分對談)

* **空間複雜度的飛躍：**
主動向面試官指出：*"This optimization reduces the space complexity from O(N) to O(1) because we replaced the explicit system stack with two competing primitive pointers, while keeping the time complexity strictly O(N)."*
* **Thread-Safety & Read-Only Pass：**
注意到傳入參數是 `const vector<int>&`。這個解法完全沒有更動到 `height` 陣列裡的任何一個數字（無副作用），非常適合並行運算（Parallel Processing）或多執行緒環境。
