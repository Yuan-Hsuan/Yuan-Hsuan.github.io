## 🎙️ Naive Solution
The naive solution is to check every possible substring of `s` to see if it contains all characters of `t`. Generating all substrings takes O(N^2) time, and checking them takes O(N), leading to an unacceptable O(N^3) time complexity. 

## 🚀 Pitch
### The Bottleneck Observation (重複掃描的痛點)
The brute-force method discards useful information. When a substring contains all characters of `t`, extending it further to the right is pointless because it will only make the valid window larger. 

### The Strategy: Sliding Window with Frequency Map (滑動視窗與頻率映射)
To achieve a strictly O(N) linear time complexity, I will use the **Sliding Window** method. We maintain two pointers, `left` and `right`, to represent our current window. 

### The Precise Execution (精準的擴張與收縮邏輯)

First, to efficiently verify the window's validity, we initialize a target frequency array of size 128 to track the required characters from t. We also maintain a `counter` that tracks the number of distinct characters in t the window hasn't fully covered yet. Once the `counter` reaches `0`, our window contains all required characters. 

As the `right` pointer expands the window, I decrement the frequency of the current character in our map. When the character's frequency hits `0`, we decrement the `counter`. 
**A brilliant property of this array is that characters *not* in `t` start at `0` and will only become negative, meaning they will never accidentally hit `0` and affect our `counter`.**

At this point, we aggressively shrink the `left` pointer using an inner `while` loop to drop any redundant characters (where frequency < 0). We only stop shrinking when we hit a character whose frequency is exactly `0`, meaning it is strictly required to keep the window valid. Finally, we record the optimal window size.

**Complexity**
- **Time — O(N):** Both `left` and `right` pointers traverse the string `s` at most once.
- **Space — O(1):** The frequency map uses a constant extra space of size 128.

## 🛠️ Optimization
```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        vector<int> umap(128, 0);
        
        int count = 0;
        for (char c : t) {
            if (umap[c] == 0) count++;
            umap[c]++;
        }

        int start = 0;
        int len = INT_MAX;
        int l = 0, r = 0;
        
        while (r < s.length()) {

            umap[s[r]]--;
            if (umap[s[r]] == 0) count--;
            
            while (l < r) {
                if (umap[s[l]] >= 0) break; 
                umap[s[l]]++;
                l++;
            }

            r++;
            
            if (count == 0 && (r - l) < len) {
                start = l;
                len = r - l;
            }
        }

        return count > 0 ? "" : s.substr(start, len);
    }
};
```
