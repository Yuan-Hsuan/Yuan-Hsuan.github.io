## 🚀 Pitch

### The Bottleneck Observation
The main challenge of this problem is managing the boundaries to avoid out-of-bound errors and double-counting, especially when dealing with non-square matrices where the inner layers might just be a single row or column.

### The Strategy: Shrinking Boundaries (Four Pointers)
To handle this efficiently, I will use a **Shrinking Boundaries** approach. I will maintain four pointers—`top`, `bottom`, `left`, and `right`—representing the physical limits of our unvisited matrix. 

### The Precise Execution
The algorithm peels the matrix **layer by layer** in a continuous `while` loop. 
For each layer, we traverse in four directions:
1. **Left to Right:** We iterate across the `top` row, then increment `top` to shrink the boundary inward.
2. **Top to Bottom:** We iterate down the `right` column, then decrement `right`.
3. **Right to Left:** We iterate across the `bottom` row, then decrement `bottom`.
4. **Bottom to Top:** We iterate up the `left` column, then increment `left`.

**Defensive Coding (The Exit Condition):**
Before traversing in any reverse direction (right-to-left or bottom-to-top), I strictly check if our boundaries have crossed (e.g., `if (left > right)` or `if (top > bottom)`). If they have, it means no elements remain, and we immediately `break` the loop.

**Complexity**
- **Time — O(M \times N):** Every element in the matrix is visited exactly once.
- **Space — O(1):** We only use four integer variables for the boundaries, not counting the output array.

## 🛠️ Optimization
```cpp
class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        if (matrix.empty() || matrix[0].empty()) return {};
        
        vector<int> res;
        int top = 0, right = matrix[0].size()-1, bottom = matrix.size()-1, left = 0;
        while (true) {
            // right
            if (right < left) break;
            for (int j = left; j <= right; j++) {
                res.push_back(matrix[top][j]);
            }
            top++;

            if (top > bottom) break;
            for (int i = top; i <= bottom; i++) {
                res.push_back(matrix[i][right]);
            }
            right--;

            if (right < left) break;
            for (int j = right; j >= left; j--) {
                res.push_back(matrix[bottom][j]);
            }
            bottom--;

            if (top > bottom) break;
            for (int i = bottom; i >= top; i--) {
                res.push_back(matrix[i][left]);
            }
            left++;
        }

        return res;
    }
};
```
