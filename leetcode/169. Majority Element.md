## 🎙️ Naive Solution
The naive approach is to use a Hash Map to count the frequencies of all elements and then find the one that exceeds `⌊N/2⌋`. This takes O(N) time but also requires O(N) extra space. We can optimize the space to O(1).

## 🚀 Pitch
### The Bottleneck Observation (問題的本質)
The core observation comes directly from the problem definition: the majority element appears strictly more than `⌊N/2⌋` times. This guarantees that it mathematically outnumbers all other elements combined.

### The Strategy: Boyer-Moore Voting Algorithm (摩爾投票法)
To achieve O(1) space, we use the **Boyer-Moore Voting Algorithm**. The intuition is essentially a **cancellation process (一對一抵銷)**. Because the majority element holds more than half of the total count, if we pair every majority element with a non-majority element, the majority element will always be the last one standing.

### The Precise Execution (精準的執行邏輯)
We maintain a `candidate` and a `count`. As we iterate through the array:
1. If `count` is 0, we pick the current number as our new `candidate` and set count to 1.
2. If the current number matches our `candidate`, we increment the count.
3. If it differs, we decrement the count (pairing them up to cancel each other out).

Because the majority element outnumbers all others, it will invariably survive this cancellation process and remain as the final candidate.

**Complexity**
- **Time — O(N):** a single pass over the array, doing O(1) work per element.
- **Space — O(1):** only the `candidate` and `count` integers, no extra storage.

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int count = 0;
        int curr = 0; // 🛡️ 防禦性習慣：給予初始值，避免編譯器 Warning
        
        for (int num : nums) {
            if (count == 0) {
                curr = num;
                count = 1;
            }
            else if (num == curr) {
                count++;
            } 
            else {
                count--;
            }
        }

        return curr;
    }
};
```
