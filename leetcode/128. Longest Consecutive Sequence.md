## 🎙️ Naive Solution
The naive approach would be to sort the input array first and then iterate through it to find the longest consecutive sequence. However, sorting takes O(N log N) time, which violates the strict O(N) time complexity constraint required by this problem.

## 🚀 Pitch
### The Bottleneck Observation (查詢效能的痛點)
To achieve an O(N) runtime, we must avoid sorting and instead find a way to look up elements in constant time. A **Hash Set** is the perfect data structure for this.

### The Strategy: Hash Set with Smart Prefix-Pruning (雜湊表與起點剪枝)
I will insert all numbers into a Hash Set to enable O(1) lookups. However, simply iterating through the set and counting upwards for every number will lead to redundant work, degrading the worst-case time complexity to O(N^2). 
To guarantee a strict O(N) runtime, we must **only start counting when we are at the absolute beginning of a sequence.**

### The Precise Execution (精準的起點判斷邏輯)
First, I convert the array into an `unordered_set`. 
Then, I iterate through the set. For each number, I check if its previous consecutive number (`num - 1`) exists in the set. 
- **If it does exist:** It means the current number is *not* the start of a sequence, so we simply skip it.
- **If it does NOT exist:** This number is a valid starting point. We then continuously check for `num + 1`, `num + 2`, etc., tracking the length of this specific sequence, and finally update our global maximum length.

**Complexity**
- **Time — O(N):** Building the Hash Set takes O(N). Because we only ever begin the inner `while` loop if `num` is the start of a sequence, each number is visited at most twice (once in the outer loop, once in the inner loop). Thus, strictly O(N).
- **Space — O(N):** For storing the numbers in the Hash Set.

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        // Initialization
        unordered_set<int> num_set(nums.begin(), nums.end());

        int res = 0;
        for (int num: num_set) {
            if (num_set.count(num-1)) continue;
            int curr = num + 1;
            while (num_set.count(curr)) {
                curr++;
            }

            res = max(res, curr - num);
        }

        return res;
    }
};
```
