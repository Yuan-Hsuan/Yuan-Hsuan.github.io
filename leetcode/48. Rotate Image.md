## 🚀 Pitch

### The Strategy

#### 1. Layer-by-Layer 4-Way Swap
The most intuitive approach is to literally rotate the matrix layer by layer. We can perform an in-place 4-way swap, moving the top-left element to the top-right, the top-right to the bottom-right, and so on. While this is strictly $O(N^2)$ in time and $O(1)$ in space, manipulating the boundary indices for each layer is highly error-prone during implementation.

#### 2. Matrix Transformation
To make the solution more elegant and robust, we can leverage basic linear algebra. Rotating a 2D matrix 90 degrees clockwise can be mathematically broken down into two simpler, independent operations:
1. Reverse on the Diagonal: Reflect the elements across the main diagonal.
2. Reverse Left to Right: Flip the matrix horizontally.

**Complexity**
- **Time — O(N^2):** We visit every element twice (once for transpose, once for reverse). Dropping the constant factor, it remains an optimal $O(N^2)$.
- **Space — O(1):** Both the transpose and the reverse operations are done entirely in-place.

## 🛠️ Code Review

#### 1. Layer-by-Layer 4-Way Swap
```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        if (matrix.empty()) return;
        
        int n = matrix.size()-1;

        for (int j = 0; j < (n+1)/2; j++) {
            for (int i = j; i < n - j; i++) {
                int temp = matrix[j][i];
                matrix[j][i] = matrix[n-i][j];
                matrix[n-i][j] = matrix[n-j][n-i];
                matrix[n-j][n-i] = matrix[i][n-j];
                matrix[i][n-j] = temp;
            }
        }
    }
};
```

#### 2. Matrix Transformation
```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        if (matrix.empty()) return;

        int n = matrix.size();

        for (int i = 0; i < n; i++) {
            for (int j = i+1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n/2; j++) {
                swap(matrix[i][j], matrix[i][n-j-1]);
            }
        }
    }
};
```
