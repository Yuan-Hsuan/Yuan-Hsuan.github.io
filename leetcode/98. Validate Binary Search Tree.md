## 🎙️ Naive Solution
To validate a Binary Search Tree, we first need to align on its strict definition: for every node, all keys in its left subtree must be strictly less than the node's key, and all keys in its right subtree must be strictly greater. Additionally, this property must hold true for all subtrees. 
Based on this definition, the most intuitive approach is to perform an In-order traversal and store the node values in an array. If the array is strictly increasing, it's a valid BST. However, this approach requires $O(N)$ extra space for the array, which is inefficient.

## 🚀 Pitch

### The Bottleneck Observation
We can optimize the space complexity by recognizing that we don't need the entire history of the traversal.

### The Strategy: In-order Traversal
Since an In-order traversal on a valid BST processes nodes in a strictly increasing order, we only need to compare the current node with the previously visited node.

### The Precise Calculation / Execution
I will implement this using a recursive In-order traversal. I'll maintain a global prev pointer initialized to null. When processing the current node, I will check if prev is not null and if the current node's value is less than or equal to prev's value. If it is, the tree is invalid, and I return false.I then update the prev pointer to the current node.Finally, I recursively check the right subtree.

**Complexity**
- **Time — O(N):** In the worst-case scenario (a valid BST), we visit every single node exactly once.
- **Space — O(H):** While our auxiliary space for the prev pointer is strictly $O(1)$, the recursive call stack will consume $O(H)$ space, where $H$ is the height of the tree.

## 🛠️ Optimization (最佳化程式碼)
```c++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    TreeNode* prev = nullptr;
    bool inorder(TreeNode* root) {
        if (root == nullptr) return true;

        if (!inorder(root->left)) return false;
        if (prev != nullptr && prev->val >= root->val) return false;
        prev = root;
        if (!inorder(root->right)) return false;
        
        return true;
    }
public:
    bool isValidBST(TreeNode* root) {
        return inorder(root);
    }
};
```

1. 你選擇紀錄 TreeNode* prev (節點指標) 而不是數值本身。透過 if (prev != nullptr) 的判斷，你優雅地處理了「第一個走訪到的節點 (最左下角的樹葉)」的問題，完全不需要管節點的值是 INT_MIN 還是什麼極端值。這種「以指標驗證狀態」的寫法，是正宗 C++ 開發者的思維。

2. 另外，你的 if (!inorder(root->left)) return false; 完美實作了 Short-circuiting (短路求值)，只要左子樹一出錯，立刻層層回傳中斷，省下了所有不必要的遍歷。
