### The Bottleneck Observation
To solve this problem, I will use Backtracking to explore the entire state space. We can visualize this process as a decision tree where each level represents a specific element from the input array.

Since every combination we encounter during the traversal is a valid subset, every single node in our decision tree is a valid answer. Therefore, the very first thing I do in the recursive function is append a copy of the current subset to the result array. We don't even need an explicit base case to terminate, because the loop boundary naturally handles it.

### The Strategy
To explore the state space, I use a for loop starting from the current index. This loop iterates through all the remaining candidate numbers.
For each number, I add it to the current subset, and recursively call the function with i + 1 to move down to the next level.

### The Precise Execution
Crucially, after the recursive call returns, I pop the last element from the current subset. This state restoration ensures that the current array is clean and ready for the next sibling branch in the for loop.

**Complexity**
- **Time — O(N × 2^N):** there are 2^N subsets and copying each into the output costs up to O(N). Both approaches below share this.
- **Space — O(N):** backtracking's recursion depth + current path (excluding output). The iterative version needs only O(1) auxiliary space.

## 🛠️ Solution

**Approach 1 — Backtracking** (the template; generalizes to 90. Subsets II, combinations, permutations)
```cpp
class Solution {
private:
    void backtrack(vector<int>& nums, int index, vector<int>& curr, vector<vector<int>>& res) {
        res.push_back(curr);

        for (int i = index; i < nums.size(); i++) {
            curr.push_back(nums[i]);
            backtrack(nums, i+1, curr, res);
            curr.pop_back();
        }
    }
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<int> curr;
        vector<vector<int>> res;
        backtrack(nums, 0, curr, res);

        return res;
    }
};
```

**Approach 2 — Iterative cascading** (shorter, no recursion stack; harder to extend to variants)
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> res;
        res.push_back({});                      // 從空集合開始
        for (int num : nums) {
            int size = res.size();              // 固定住舊長度，只擴充現有子集
            for (int i = 0; i < size; i++) {
                vector<int> v = res[i];
                v.push_back(num);
                res.push_back(v);               // 每個現有子集 + num → 集合數翻倍
            }
        }
        return res;
    }
};
```
