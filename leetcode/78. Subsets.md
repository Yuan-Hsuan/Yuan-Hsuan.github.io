## 🚀 Pitch

### The Strategy: Backtracking
I'd model this as a backtracking problem. The problem wants **every** subset, so I have to build
each one. I visualize it as a decision tree where each level represents a specific element from the
input array.

### The Precise Execution
To implement the backtracking, at each step:

- **The state.** I would carry two values down: `index`, the position where the remaining
  candidates start, and `curr`, the elements I've already picked.
- **The decision.** I decide **which of the remaining elements I take next**.
- **The options.** Every element from `index` to the end of the array.
- **The undo.** After each call returns, I pop the last element from `curr`. This state restoration
  keeps `curr` clean and ready for the next sibling branch in the for loop.

To finalize:

- **The record.** Every combination I pass through is a valid subset, so every single node in the
  decision tree is an answer. That means the first thing I do in the recursive function is append a
  copy of `curr` to the result. I don't even need an explicit base case, because the loop boundary
  naturally handles termination.

There is nothing to prune here:

- **The pruning.** Every branch is valid, so no legality check applies. I also don't need any
  dedup, because recursing with `i + 1` never revisits an element, so the same subset can't be
  built twice.

**Complexity**
- **Time — O(N × 2^N):** there are 2^N subsets and copying each into the output costs up to O(N). Both approaches below share this.
- **Space — O(N):** backtracking's recursion depth + current path (excluding output). The iterative version needs only O(1) auxiliary space.

## 🛠️ Solution

**Approach 1 — Backtracking** (the template; generalizes to 90. Subsets II, combinations, permutations)
```cpp
class Solution {
private:
    void backtrack(vector<int>& nums, int index, vector<int>& curr, vector<vector<int>>& res) {
        res.push_back(curr);

        for (int i = index; i < nums.size(); i++) {
            curr.push_back(nums[i]);
            backtrack(nums, i+1, curr, res);
            curr.pop_back();
        }
    }
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<int> curr;
        vector<vector<int>> res;
        backtrack(nums, 0, curr, res);

        return res;
    }
};
```

**Approach 2 — Iterative cascading** (shorter, no recursion stack; harder to extend to variants)
```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> res;
        res.push_back({});                      // 從空集合開始
        for (int num : nums) {
            int size = res.size();              // 固定住舊長度，只擴充現有子集
            for (int i = 0; i < size; i++) {
                vector<int> v = res[i];
                v.push_back(num);
                res.push_back(v);               // 每個現有子集 + num → 集合數翻倍
            }
        }
        return res;
    }
};
```
