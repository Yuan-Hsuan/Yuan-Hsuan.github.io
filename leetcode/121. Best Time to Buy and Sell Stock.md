## 🎙️ Naive Solution

The naive approach is to use nested loops to explore every possible pair of buy and sell days. We calculate the profit for every combination where we buy on day i and sell on day j (where j > i). This takes O(N^2) time complexity, which is highly inefficient for large arrays.

## 🚀 Pitch

### The Bottleneck Observation (歷史最低價的決定性)

The core objective is to maximize the difference between the buying price and the selling price, under the constraint that the buying day must precede the selling day. When we iterate through the array from left to right, we don't need to look back at all previous prices individually. We only care about the historical lowest price seen prior to the current day.

### The Strategy: Tracking Historical Minimum (單次走訪貪婪法)

To achieve O(N) time and O(1) space, we can maintain a running record of the minimum price we have encountered so far. As we scan the array, we treat each day's price as a potential selling day and calculate the profit relative to our historical minimum.

### The Precise Calculation / Execution (雙狀態更新)

We initialize buy with the first day's price and sell (which represents the max profit) as 0.
For each price, we perform two O(1) updates in order:

Update our maximum profit: sell = max(sell, current_price - buy)

Update our historical minimum: buy = min(buy, current_price)
This completely eliminates redundant scanning, achieving the absolute fastest O(N) time in a single pass.

**Complexity**
- **Time — O(N):** N = `prices.size()`; a single pass with two O(1) updates per day.
- **Space — O(1):** only the `buy` minimum and `sell` max-profit scalars.

## 🛠️ Optimization (原始程式碼待優化區)

* 致命的空陣列崩潰 (Out of Bounds / Segmentation Fault)：

    * 原著寫法： 一開始直接呼叫 int buy = prices[0];。
    * 錯誤情境： 如果傳入的 prices 是空的（長度為 0），prices[0] 會直接觸發 Undefined Behavior 或 Segmentation Fault，導致程式崩潰。
    * 優化建議： 必須在最開頭加入防禦性檢查，若為空陣列則直接回傳 0。

* C++ 效能細節 (Range-based Loop Optimization)：

    * 原著寫法： for( auto price: prices )
    * 優化建議： 雖然 int 的複製開銷極小，但使用 const auto& price 或直接寫 int price 是更規範的 C++ 寫法，能展現出良好的 Code Style 與對底層記憶體複製的敏感度。

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        // 🛡️ 防禦性編程：攔截空陣列，防止 prices[0] 崩潰
        if (prices.empty()) return 0;

        int buy = prices[0];
        int sell = 0; // 儲存最大利潤

        // 使用 const auto& 避免不必要的物件拷貝
        for (const auto& price : prices) {
            sell = max(sell, price - buy); // 嘗試在今天賣出，更新最大利潤
            buy = min(buy, price);         // 更新歷史最低買入價
        }

        return sell;
    }
};
```

## 🛡️ Defensive Coding (防禦性編程)

* 空輸入防護 (Empty Input Guard)：
在進行任何陣列索引操作（如 prices[0]）之前，永遠先檢查 prices.empty()。在實際的面試中，這行程式碼能直接幫你避開面試官的邊界條件測試 (Edge Case Test)。
