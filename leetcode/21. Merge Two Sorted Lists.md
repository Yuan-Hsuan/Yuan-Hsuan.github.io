## 🚀 Pitch
### The Bottleneck Observation
Since both input lists are already sorted, we can merge them in a single pass. The main challenge in linked list manipulation is handling the edge cases gracefully.

### The Strategy: Two Pointers with a Dummy Node (虛擬節點模式)
I will use a **Two-Pointer** approach to iterate through both lists. More importantly, I will introduce a **"Dummy Node"** at the beginning of our merged list. This defensive programming technique eliminates the need for complex `if-else` checks to determine which node becomes the new `head`, keeping the code exceptionally clean.

### The Precise Execution
I will use a `tail` pointer starting at the dummy node. While both `list1` and `list2` are not null, I compare their values, attach the smaller node to `tail->next`, and advance the corresponding pointer. 
Once the `while` loop terminates (meaning at least one list is exhausted), I simply **connect (直接拼接)** the remaining nodes of the non-empty list directly to the `tail`. Finally, I return `dummy.next` as the head of the merged list.

**Complexity**
- **Time — O(N + M):** N and M are the lengths of the two lists. We traverse each node at most once.
- **Space — O(1):** We only reassign the `next` pointers in-place without allocating any new nodes.

---

## 🛠️ Optimization (最佳化程式碼)
```cpp
while (list1 && list2) {
    if (list1->val < list2->val) {
        tail->next = list1;
        list1 = list1->next;
    } else {
        tail->next = list2;
        list2 = list2->next;
    }
    tail = tail->next; // 🌟 統一推進，乾淨俐落
}

// 🌟 三元運算子，一行完成尾段拼接
tail->next = list1 ? list1 : list2;
```
