## 🚀 Pitch

### The Bottleneck Observation
Since the input array is already sorted, any duplicate elements are guaranteed to be naturally grouped together (contiguous). This property allows us to resolve the problem in a single pass without any extra memory. And the problem allows us to ignore the remaining elements past the returned length. This means instead of physically deleting elements, we can simply **overwrite** the duplicates with unique elements.

### The Strategy: Two Pointers
I will use a **Two-Pointer technique**—specifically, a "Reader" (fast pointer) and a "Writer" (slow pointer) pointer.

Use a **reader pointer** to iterate through the entire vector, and a **writer pointer** that points to the exact position where the next unique element should be written.

### The Precise Calculation / Execution
As we iterate, whenever the scan pointer finds a new unique element, we overwrite the value at the
write pointer with it and then increment the write pointer. This processes the array in a single
pass.

**Complexity**
- **Time — O(N):** a single scan-pointer pass over the array.
- **Space — O(1):** only use in-place overwrites with a write pointer, no allocations.

## 🛠️ Solution
```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        // 🛡️ 完美的防禦：處理空陣列的極端情況
        if (nums.empty()) return 0;

        int pos = 1;
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] != nums[i-1]) {
                nums[pos++] = nums[i];
            }
        }

        return pos;
    }
};
```
