## ⚠️ Warning
Don't reach for a Hash Map here. Because the problem forbids duplicate triplets, a hash-based
approach forces an extra HashSet for deduplication — paying a heavy constant-factor and O(N) space
penalty. Sort the array and use two pointers instead, which skips duplicates naturally in O(1) space.

## 🎙️ Naive Solution
The naive approach is to check every possible combination of three numbers, resulting in an O(N^3) time complexity. We could theoretically optimize the time to O(N^2) using a Hash Map (like in 2Sum). However, the problem strictly constrains that the solution set must not contain duplicate triplets. Using a Hash Map or HashSet for deduplication, which introduces a massive constant time overhead and an O(N) space penalty.

## 🚀 Pitch

### The Bottleneck Observation
The core challenge isn't just finding the triplets, but **guaranteeing absolute uniqueness** without paying a massive space and performance penalty. 

### The Strategy: Sorting + Two Pointers (排序與雙指標)
To solve this elegantly in strictly O(1) extra space, I will use a **Sorting + Two Pointers** approach. 
Sorting the array provides two massive benefits: naturally grouping identical numbers together (making it incredibly easy to skip duplicates) and organizing the values in increasing order, which makes the two-pointer technique straightforward to apply.

### The Precise Calculation / Execution
With the array sorted, we iterate through it, fixing each number
as our "pivot." This reduces the 3Sum problem into a 2Sum problem: we just need to find two numbers
that sum to the complement of the pivot. We set a `left` pointer immediately to the right of the
pivot and a `right` pointer at the end of the array, dynamically moving them inwards based on the sum.

**Strict deduplication (嚴格去重).** During this process, because the array is sorted, we actively
skip adjacent duplicate values to ensure strictly unique triplets.

**Complexity**
- **Time — O(N^2):** N = `nums.size()`; sort is O(N log N), then each pivot runs an O(N) two-pointer scan.
- **Space — O(1):** sorts in place with only pointers, excluding the output list and sort's stack.

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        if (nums.size() < 3) return {};

        sort(nums.begin(), nums.end());
        
        vector<vector<int>> res;
        int n = nums.size();

        // 使用 for 迴圈讓結構更清晰
        for (int i = 0; i < n - 2; i++) {
            
            // 🌟 Senior Move: Early Termination (提早結束)
            // 如果最左邊的數字已經大於 0，後面的數字相加不可能等於 0
            if (nums[i] > 0) break;

            // Pivot 去重：跳過與前一個相同的數字
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int l = i + 1;
            int r = n - 1;

            while (l < r) {
                // 統一計算 sum，避免正負號轉換的混淆
                int sum = nums[i] + nums[l] + nums[r];
                
                if (sum == 0) {
                    res.push_back({nums[i], nums[l], nums[r]});
                    l++;
                    r--;
                    
                    // Left pointer 去重
                    while (l < r && nums[l] == nums[l - 1]) l++;
                    // Right pointer 去重
                    while (l < r && nums[r] == nums[r + 1]) r--;
                } 
                else if (sum < 0) {
                    l++;
                    // (Optional) 提早跳過重複值，加速執行
                    while (l < r && nums[l] == nums[l - 1]) l++;
                } 
                else {
                    r--;
                    // (Optional) 提早跳過重複值，加速執行
                    while (l < r && nums[r] == nums[r + 1]) r--;
                }
            }
        }

        return res;
    }
};
```
