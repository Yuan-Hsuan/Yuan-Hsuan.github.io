## 🎙️ Naive Solution
To solve this problem, a naive approach would be rotating the array one step at a time for $k$ iterations, which takes $O(N \times K)$ time. Alternatively, we could use an extra array to place elements into their correct positions, but that requires $O(N)$ extra space.

## 🚀 Pitch

### The Bottleneck Observation
To optimize it, another trick is the 3-step reverse method, which allows us to rotate the array completely in-place without using extra space.

### The Strategy
First, we must handle the edge case where $k$ is larger than the array length by taking $k = k \pmod n$.

### The Precise Execution
Then, we can achieve the rotation in three simple steps using an in-place swap function: We reverse the entire array. We reverse the first $k$ elements. We reverse the remaining $n - k$ elements.

**Complexity**
- **Time — $O(N)$:** since each element is swapped at most twice
- **Space — $O(1)$:**

## 🛠️ Solution
```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        k %= nums.size();
        reverse(nums.begin(), nums.end());
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());
    }
};
```
