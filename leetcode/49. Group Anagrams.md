## 🚀 Pitch

### The Bottleneck Observation (尋找唯一特徵值)
The core of this problem is finding a **"unique identity" or "signature"** for anagrams so that we can group them together in a Hash Map. 

### The Sub-optimal Strategy (Sorting-based)
The most straightforward approach is to sort each string alphabetically. Anagrams will naturally become identical after sorting, serving as our unique key. However, if we have $N$ words and the maximum length of a word is $K$, sorting each word takes $O(K \log K)$, leading to an overall time complexity of **O(N * K log K)**. 

### The Optimal Strategy: Frequency Map Serialization (頻率映射與序列化)
Since the problem specifies that the strings only contain lowercase English letters, we can optimize the key generation. Instead of sorting, we can count the frequencies of the 26 characters in O(K) time for each word. 
We then serialize this frequency array into a specific string format (e.g., using a delimiter like "1#0#2#..." or appending counts to characters like "a1b0c2..."). This serialized string acts as our unique $O(K)$ signature.

**Complexity**
- **Time — O(N * K):** We iterate through $N$ words, and for each word of length $K$, we count characters in $O(K)$ time.
- **Space — O(N * K):** We store all the words in the Hash Map and the resulting arrays.

## 🛠️ Optimization
```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> anagrams;

        for (const string& str : strs) { // 🛡️ 加上 const，避免意外修改原字串
            vector<int> freq(26, 0);
            for (char c : str) {
                freq[c - 'a']++;
            }

            string id;
            id.reserve(str.size()); // 🛡️ 預先分配記憶體，避免字串動態擴展的效能損耗
            for (int c = 0; c < 26; c++) {
                if (freq[c] > 0) {
                    // 🛡️ C++ 內建語法：直接附加 freq[c] 個字元 ('a' + c)
                    id.append(freq[c], 'a' + c); 
                }
            }

            anagrams[id].push_back(str);
        }

        vector<vector<string>> res;
        res.reserve(anagrams.size()); // 🛡️ 預先分配結果陣列的空間

        // 🛡️ C++17 結構化綁定 (Structured Binding) + std::move 達成零拷貝轉移
        for (auto& [key, vec] : anagrams) { 
            res.push_back(std::move(vec)); 
        }

        return res;
    }
};
```
