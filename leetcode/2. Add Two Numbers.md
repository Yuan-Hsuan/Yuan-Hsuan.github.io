## 🚀 Pitch

### The Strategy
The digits are already stored **least-significant-first**, which is exactly the order elementary-school
addition walks — so the head node is the ones place and we can add front-to-back **without reversing
anything**. Just like manual math, we add the two current nodes plus the `carry`: the new digit is the
remainder (`sum % 10`), and the carry is the quotient (`sum / 10`).

### The Precise Calculation / Execution: Dummy Head + Unified Loop
- **Dummy Head:** to avoid messy initialization logic for the very first result node, attach new nodes
  to a dummy and simply return `dummy.next` at the end.
- **Single unified loop:** instead of separate loops for uneven lists and a leftover carry, one loop
  runs as long as either list has remaining nodes **or** the carry is non-zero (e.g. `99 + 1 = 100`).

**Complexity**
- **Time — O(max(m, n)):** a single pass, one node processed per iteration over the longer list.
- **Space — O(1) extra:** only `carry` and a moving pointer. The result list is O(max(m, n)), but
  that's the required output, not extra working memory — worth stating this distinction out loud.

## 🛠️ Optimization
```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {

        // 1. Stack Allocation 解決 Memory Leak，這是一個大亮點
        ListNode dummy(0);
        ListNode* curr = &dummy;

        int carry = 0;

        // 2. 利用隱式轉換讓 Unified Loop 條件更簡潔
        while (l1 || l2 || carry) {
            int n1 = l1 ? l1->val : 0;
            int n2 = l2 ? l2->val : 0;

            int sum = n1 + n2 + carry;
            curr->next = new ListNode(sum % 10);
            carry = sum / 10;

            curr = curr->next;

            // 3. 簡潔的指標推進
            if (l1) l1 = l1->next;
            if (l2) l2 = l2->next;
        }

        return dummy.next;
    }
};
```

## 💡 教練點評與面試加分亮點

1. **Stack Allocation vs. Heap Allocation（記憶體管理細節）**
   你的寫法是 `ListNode dummy(0);`，這在 C++ 面試中是一個大加分項。高達 80% 的人會寫
   `ListNode* dummy = new ListNode(0);`，卻在 `return dummy->next;` 時忘記 `delete dummy;` 而造成
   Memory Leak。你把 dummy 宣告在 stack 上、函式結束自動回收，展現了對 C++ 記憶體生命週期的敏銳度。

2. **"Carry + Unified Loop" 框架（一通百通）**
   "Dummy Head + Unified Loop" 是一個萬用模板，遇到「大數運算」或「雙指標合併」都能直接套用：
   - LeetCode 415. Add Strings（字串相加）
   - LeetCode 67. Add Binary（二進位字串相加）
   - LeetCode 21. Merge Two Sorted Lists（沒有 carry，但 Dummy Head + Unified Loop 邏輯完全一致）
