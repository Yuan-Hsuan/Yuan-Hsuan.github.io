## 🚀 Pitch

### The Strategy: Backtracking with a Bitmask
I'd model this as a backtracking problem. The problem wants **every** permutation of the array, so
I have to build each one, and I model it as a decision tree.

### The Precise Execution
To implement the backtracking, at each step:

- **The state.** I would carry two values down: `mask`, an integer bitmask marking which indices
  are already used, and `curr`, the path I've built so far. A bitmask is the cheapest way to track
  visited elements, and it's clean here because the constraints are small (N <= 6).
- **The decision.** I decide **which unused number goes in the current position**.
- **The options.** Every index whose bit is not set in the mask.
- **The undo.** I run the pick-up a number → explore → un-pick-up loop: push the number onto
  `curr`, recurse with the bit set, then pop it back off.

To finalize:

- **The record.** When the mask is filled with ones — that is, `curr` is as long as the input — I've
  used every number, so I record the current path.

There is nothing to prune here:

- **The pruning.** Every unused number is a legal choice, so no branch dies early. Dedup only
  becomes an issue once the input can repeat, which is the follow-up below.

**Complexity**
- **Time — O(N × N!):** there are `N!`(n factorial) leaves (complete permutations); each one costs an extra O(N) to
  copy the finished path into the result.
> Finding permutations is a well-studied problem in combinatorics. Given a set of length n, the number of permutations is n! (n factorial). There are n options for the first number, n−1 for the second, and so on. For each of the n! permutations, we need O(n) work to copy curr into the answer. This gives us O(n⋅n!) work.
- **Space — O(N):** recursion depth is `n` plus the O(N) `curr` path; the bitmask is O(1).

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
private:
    void backtracking(vector<int>& nums, int mask, vector<int>& curr, vector<vector<int>>& res) {

        if (curr.size() == nums.size()) {        
            res.push_back(curr);
            return;
        }

        for (int i = 0; i < nums.size(); i++) {
            int num = nums[i];

            if ((mask >> i) & 1) {      
                continue;
            }

            curr.push_back(num);        
            backtracking(nums, mask | (1 << i), curr, res);                
            curr.pop_back();            
        }
    }
public:
    vector<vector<int>> permute(vector<int>& nums) {
        vector<int> curr;
        vector<vector<int>> res;
        backtracking(nums, 0, curr, res);

        return res;
    }
};
```
