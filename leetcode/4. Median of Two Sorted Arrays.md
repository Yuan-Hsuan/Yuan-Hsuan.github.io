## 🎙️ Naive Solution
The naive approach is to use two pointers to merge the arrays until we reach the median, which takes $O(N+M)$ time.

## 🚀 Pitch

### The Bottleneck Observation: **Find a perfect partition across both arrays (尋找完美的跨陣列切分線).** 
However, since both arrays are already sorted, this monotonic property is exactly why Binary Search works perfectly here. We can optimize this to $O(\log(\min(N, M)))$ by using Binary Search.
The median fundamentally divides a dataset into two equal halves. In a single sorted array we simply cut in the center. Even though we are given two arrays, the total number of elements in the left half is fixed, making a cut in Array A strictly determines the cut in Array B. So, our goal is to finding a perfect **partition (cut)** across both arrays, such that the left half holds the same number of elements as the right half, and all left elements are strictly smaller than the right elements.

### The Strategy: Binary Search on the Cut (刀口理論)

I will perform the binary search on the smaller array to minimize the search space. If I make a cut1 in the first array, the position of cut2 in the second array is automatically determined because the total number of elements on the left side must equal half of the total combined length.

### The Precise Calculation / Execution

To verify a partition is correct, we only need to cross-check the four elements adjacent to the cuts: 

L1, R1 from the first array, and L2, R2 from the second. A perfect partition is found when L1 <= R2 and L2 <= R1.

* If L1 > R2, it means our cut in the first array is too far right, so we move our search space to the left.
* If L2 > R1, we move to the right.Once we find the perfect cut, calculating the median is strictly $O(1)$ based on the maximums of the left side and minimums of the right side.

**Complexity**
- **Time — O(log(min(M, N))):** binary search over cut positions in the shorter array only.
- **Space — O(1):** a constant set of boundary variables; the recursion swaps arrays just once.

## 🛠️ Optimization
```c++
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        
        if (nums1.size() > nums2.size()) return findMedianSortedArrays(nums2, nums1);

        int n = nums1.size();
        int m = nums2.size();
        int half = (n+m+1)/2;

        int l = 0;
        int r = n;
        while (l <= r) {
            int mid1 = l + (r-l)/2;
            int mid2 = half - mid1;

            int L1 = mid1 == 0? INT_MIN : nums1[mid1-1];
            int R1 = mid1 == n? INT_MAX : nums1[mid1];
            int L2 = mid2 == 0? INT_MIN : nums2[mid2-1];
            int R2 = mid2 == m? INT_MAX : nums2[mid2];

            if (L1 <= R2 && L2 <= R1) {
                if ((n+m) % 2 == 1) {
                    return max(L1, L2);
                } else {
                    return (double)(max(L1, L2) + min(R1, R2)) / 2.0;
                }
            } else if (L1 > R2) {
                r = mid1;
            } else {
                l = mid1 + 1;
            }
        }

        return -1;
    }
};
```
