## 🎙️ Naive Solution
The naive approach is to use two pointers to merge the two sorted arrays into a single array, and then simply pick the middle element. That costs O(M + N) time and space.

## 🚀 Pitch

### The Bottleneck Observation: **Find a perfect partition across both arrays (尋找完美的跨陣列切分線).** 
The median fundamentally divides a dataset into two equal halves. In a single sorted array we simply cut in the center.
Since this problem gives us two arrays, our goal shifts to finding a perfect **partition (cut)**
across both arrays, such that the left half holds the same number of elements as the right half (or
exactly one more when the total length is odd — that one extra element is the median itself), and all
left elements are strictly smaller than the right elements.

### The Strategy: Binary Search on the Cut (刀口理論)
Because the total number of elements in the left half is fixed, making a cut in Array A strictly determines the cut in Array B.
By applying Binary Search on the smaller array of length `m`, which mathematically
guarantees an O(log(min(M, N))) time complexity.

### The Precise Calculation / Execution
**Cross-checking the boundaries (交叉驗證切分線的合法性).** To verify a partition is correct, we only
need to cross-check the four elements immediately adjacent to the cuts: 

1. If `maxLeftX <= minRightY` AND `maxLeftY <= minRightX`, we have found the perfect partition! We can then calculate the median based on whether the total length is odd or even.
2. If `maxLeftX > minRightY`, our partition in X is too far right, so we move our search space to the left.
3. Otherwise, we move to the right.

This monotonic property is exactly why
Binary Search works perfectly here.

**Complexity**
- **Time — O(log(min(M, N))):** binary search over cut positions in the shorter array only.
- **Space — O(1):** a constant set of boundary variables; the recursion swaps arrays just once.

## 🛠️ Optimization
```c++
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        
        if (nums1.size() > nums2.size()) return findMedianSortedArrays(nums2, nums1);

        int n = nums1.size();
        int m = nums2.size();
        int half = (n+m+1)/2;

        int l = 0;
        int r = n;
        while (l <= r) {
            int mid1 = l + (r-l)/2;
            int mid2 = half - mid1;

            int L1 = mid1 == 0? INT_MIN : nums1[mid1-1];
            int R1 = mid1 == n? INT_MAX : nums1[mid1];
            int L2 = mid2 == 0? INT_MIN : nums2[mid2-1];
            int R2 = mid2 == m? INT_MAX : nums2[mid2];

            if (L1 <= R2 && L2 <= R1) {
                if ((n+m) % 2 == 1) {
                    return max(L1, L2);
                } else {
                    return (double)(max(L1, L2) + min(R1, R2)) / 2.0;
                }
            } else if (L1 > R2) {
                r = mid1;
            } else {
                l = mid1 + 1;
            }
        }

        return -1;
    }
};
```
