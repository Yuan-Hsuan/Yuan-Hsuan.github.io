> 這題是 [[lc-permutations]]（46. Permutations）的延伸：輸入**有重複數字**，要避免產生重複的排列。

## 🚀 Pitch

### The Strategy: Sorting + Relative Order Pruning
Same decision tree as 46, with one problem: treating identical elements as distinct items generates
identical permutations. To eliminate that, I have to stop the algorithm from exploring redundant
branches. So I **sort the input first** — sorting groups every set of duplicates together, which is
what makes the dedup rule expressible in one line.

### The Precise Execution
To implement the backtracking, at each step:

- **The state.** I would carry two values down: `mask` (or a `visited` array) marking which
  elements are currently in my path, and `curr`, the path so far.
- **The decision.** I decide **which unused number goes in the current position**.
- **The options.** Every index whose bit is not set in the mask.
- **The undo.** Push the number onto `curr`, recurse with the bit set, then pop it back off.

To finalize:

- **The record.** When `curr` is as long as the input, I record the path.

To kill the duplicates, I return early when:

- **The pruning.** Because sorting puts equal values next to each other, I can force every group of
  duplicates to be used **strictly left-to-right** — and that is exactly what removes the repeats.
  So when the current number equals the previous one (`nums[i] == nums[i-1]`), I only allow it if
  that previous twin is already in the path. If the previous twin is still unused (`!used[i-1]`), I
  would be using the duplicates *out of order*, which just regenerates a subtree I already
  explored, so I cut it.

  Think of the two ones in `[1,1,2]` as `1ᵃ 1ᵇ`: the branch `1ᵇ 1ᵃ 2` is pruned the instant I reach
  `1ᵇ` while `1ᵃ` is still unused, leaving only `1ᵃ 1ᵇ 2`. This guarantees 100% unique permutations.

**Complexity**
- **Time — O(N × N!):** In the worst case (all unique elements), there are N! permutations. Generating each takes O(N).
- **Space — O(N):** For the recursion stack and the current path / visited array.

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
private:
    void backtracking(vector<int>& nums, int mask, vector<int>& curr, vector<vector<int>>& res) {

        if (curr.size() == nums.size()) {
            res.push_back(curr);
            return;
        }

        for (int i = 0; i < nums.size(); i++) {
            int num = nums[i];

            if ((mask >> i) & 1) {
                continue;
            }

            if (i > 0 && nums[i] == nums[i-1] && !((mask >> (i-1)) & 1)) {
                continue;
            }

            curr.push_back(num);
            backtracking(nums, mask | (1 << i), curr, res);
            curr.pop_back();
        }
    }
public:
    vector<vector<int>> permuteUnique(vector<int>& nums) {
        vector<int> curr;
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());
        backtracking(nums, 0, curr, res);

        return res;
    }
};
```
