> 這題是 [[lc-permutations]]（46. Permutations）的延伸：輸入**有重複數字**，要避免產生重複的排列。

## 🚀 Pitch

### The Bottleneck Observation (重複排列的根源)
The core issue with duplicate elements is that treating them as distinct items generates identical permutations in our decision tree. To eliminate this, we must prevent the algorithm from exploring redundant branches.

### The Strategy: Sorting + Relative Order Pruning
To solve this efficiently, I will use **Backtracking with pruning**. 
First, I will **sort the input array**. Sorting ensures that all identical numbers are grouped together, which makes the deduplication logic much easier.

### The Precise Execution (精準的剪枝執行)
During the backtracking process, we maintain a `visited` array (or bitmask) to track which elements are currently in our path, and skip any element that has already been visited.

**The Pruning Core.** Because sorting puts equal values next to each other, we can force every group of duplicates to be used **strictly left-to-right** — and that is exactly what removes the repeats. So when the current number equals the previous one (`nums[i] == nums[i-1]`), we only allow it **if that previous twin is already in the path**. If the previous twin is still unused (`!used[i-1]`), we would be using the duplicates *out of order*, which just regenerates a subtree we already explored — so we cut it.

Think of the two ones in `[1,1,2]` as `1ᵃ 1ᵇ`: the branch `1ᵇ 1ᵃ 2` is pruned the instant we reach `1ᵇ` while `1ᵃ` is still unused, leaving only `1ᵃ 1ᵇ 2`. This guarantees 100% unique permutations.

**Complexity**
- **Time — O(N × N!):** In the worst case (all unique elements), there are N! permutations. Generating each takes O(N).
- **Space — O(N):** For the recursion stack and the current path / visited array.

## 🛠️ Optimization (最佳化程式碼)
```cpp
class Solution {
private:
    void backtracking(vector<int>& nums, int mask, vector<int>& curr, vector<vector<int>>& res) {

        if (curr.size() == nums.size()) {
            res.push_back(curr);
            return;
        }

        for (int i = 0; i < nums.size(); i++) {
            int num = nums[i];

            if ((mask >> i) & 1) {
                continue;
            }

            if (i > 0 && nums[i] == nums[i-1] && !((mask >> (i-1)) & 1)) {
                continue;
            }

            curr.push_back(num);
            backtracking(nums, mask | (1 << i), curr, res);
            curr.pop_back();
        }
    }
public:
    vector<vector<int>> permuteUnique(vector<int>& nums) {
        vector<int> curr;
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());
        backtracking(nums, 0, curr, res);

        return res;
    }
};
```
