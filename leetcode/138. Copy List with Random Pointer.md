## 🎙️ Naive Solution
The naive approach is to use a Hash Map to store the mapping between original nodes and their corresponding copied nodes. This takes O(N) time but requires O(N) extra space. The challenge is to optimize this space complexity to strictly O(1).

## 🚀 Pitch

### The Bottleneck Observation (空間複雜度的瓶頸)
The only reason we need a Hash Map is to look up the newly created copied nodes when we are setting the random pointers. If we can conceptually "bind" the copied node to the original node using existing pointer structures, we can eliminate the Hash Map entirely.

### The Strategy: Node Interleaving (節點交錯綁定)
To achieve O(1) space, we can insert each copied node immediately after its original node (`A -> A' -> B -> B'`), so we effectively use the `next` pointer as our Hash Map.

### The Precise Execution (精準的三步走邏輯)
I will use a 3-Pass Algorithm with a Node Interleaving trick. 
1. **Pass 1 — Duplication & Interleaving:** iterate the original list; for each node, create a deep copy and insert it directly between the current node and its next node.
2. **Pass 2 — Random Pointer Assignment:** iterate the interleaved list. For any original node, its copy is simply `curr->next`, so the copy's random is `curr->random->next` (taking care to handle null random pointers safely).
3. **Pass 3 — List Restoration & Extraction:** a final pass disentangles the interleaved list into two
   distinct lists — returning the deep-copy head while strictly restoring the original list to its
   initial state, avoiding any unintended side effects.

**Complexity**
- **Time — O(N):** three linear passes over the list.
- **Space — O(1) extra:** the interleaving reuses `next` pointers instead of a hash map; the copied list is the required output, not extra working memory.

## 🛠️ Optimization (最佳化程式碼)
```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* next;
    Node* random;

    Node(int _val) {
        val = _val;
        next = NULL;
        random = NULL;
    }
};
*/

class Solution {
public:
    Node* copyRandomList(Node* head) {
        // 🛡️ 防禦性編程：提早處理空指標
        if (head == nullptr) return nullptr;

        // 1. Pass 1: Duplication & Interleaving
        Node* curr = head;
        while (curr != nullptr) {
            Node* nxt = curr->next;
            curr->next = new Node(curr->val);
            curr->next->next = nxt;
            curr = nxt;
        }

        // 2. Pass 2: Random Pointer Assignment
        curr = head;
        while (curr != nullptr) {
            // 🛡️ 防禦 Null Pointer：確保 random 存在才進行賦值
            if (curr->random != nullptr) {
                curr->next->random = curr->random->next;
            }
            curr = curr->next->next;
        }

        // 3. Pass 3: List Restoration & Extraction
        // 🌟 Senior 細節：使用 Stack Allocation 配置 Dummy Node 避免 Memory Leak
        Node dummy(0);
        Node* newcurr = &dummy;
        curr = head;

        while (curr != nullptr) {
            // 抽取新的 Node
            newcurr->next = curr->next;
            newcurr = newcurr->next;

            // 完美還原原本的 List
            curr->next = newcurr->next;
            curr = curr->next;
        }

        return dummy.next;
    }
};
```
