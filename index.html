Sorting is essential because **the problem strictly23constrains that the solution set must not contain duplicate triplets**. Sorting naturally groups24identical numbers together for easy skipping, and it creates an increasing order that **makes the25two-pointer technique straightforward to apply**.2627### The Strategy: Reduction to 2Sum (降維打擊)28**Reduction to 2Sum (化簡為 2Sum).** With the array sorted, we iterate through it, fixing each number29as our "pivot." This reduces the 3Sum problem into a 2Sum problem: we just need to find two numbers30that sum to the complement of the pivot. We set a `left` pointer immediately to the right of the31pivot and a `right` pointer at the end of the array, dynamically moving them inwards based on the sum.3233### The Precise Calculation / Execution34**Strict deduplication (嚴格去重).** During this process, because the array is sorted, we actively35skip adjacent duplicate values to ensure strictly unique triplets.3637## 🛠️ Solution38Sort the array; for each pivot index, run a two-pointer scan (`left` just after the pivot, `right`39at the end) that shrinks inward toward the pivot's complement, and skip adjacent duplicates at both40the pivot level and the pointer level. This turns the O(N^3) brute force into an O(N^2) scan while41guaranteeing unique triplets.
1---2id: lc-largest-rectangle-in-histogram3domain: leetcode4title: 84. Largest Rectangle in Histogram5tags: [array, stack, monotonic-stack]6difficulty: hard7status: review8mastery: 59importance: 510optimal: true11source: https://leetcode.com/problems/largest-rectangle-in-histogram/12visibility: public13---1415## 🎙️ Naive Solution16The naive solution for this problem would be to check every possible combination of left and right17boundaries, which gives us an **O(N^2)** time complexity.1819## 🚀 Pitch2021### The Bottleneck Observation22We can optimize by focusing on a key observation: the height of any rectangle is strictly determined23by the shortest bar inside it. This means as we iterate through the histogram from left to right,24whenever we encounter a shorter bar, the taller bars before it can no longer be extended to the25right. For example, if the heights are `[2, 1, 5, 6]`, the moment we hit the `1`, we no longer need26to look back at the `2` because `1` becomes the new bottleneck.2728### The Strategy: Monotonic Increasing Stack29We use this observation to design an O(N) algorithm with a Monotonic Increasing Stack. Instead of30constantly looking back, we only keep track of heights in increasing order.3132### The Precise Calculation / Execution33Whenever we encounter a bar that is shorter than the top of our stack, it means we have found the34**right boundary** for that taller bar. So we pop the taller bar out to calculate its maximum area.35The **height** of the rectangle is simply the height of the bar we just popped. The **left boundary**36is the *new* top of our stack — because our stack is strictly increasing, the new top is the first37bar on the left that is shorter. Therefore the width is the distance between the current index and38the new top of the stack, minus one. We calculate this area right then and there, update our maximum,39and discard the popped bar.4041## 🛠️ Optimization42```c++43class Solution {44public:45    int largestRectangleArea(vector<int>& heights) {46        stack<int> st;47        // 創造左邊界48        st.push(-1);49        // 避免最後多一個迴圈判斷50        heights.push_back(0);5152        int n = heights.size();53        int res = 0;54        for (int i = 0; i < n; i++) {5556            while (st.top() != -1 && heights[st.top()] > heights[i]) {5758                int height = heights[st.top()];59                st.pop();6061                res = max(res, (i - st.top() - 1) * height);62            }6364            st.push(i);65        }6667        // 恢復原始輸入資料68        heights.pop_back();6970        return res;71    }72};73```

The setup: SGD needs the gradient 起點:SGD 要梯度1819A net is stacked linear layers + non-linearities: $z=Wx+b,\ a=f(z)$ (activation applied **element-wise**).20Training = **SGD**: 訓練就是梯度下降:21$$\theta^{new}=\theta^{old}-\alpha\,\nabla_\theta J(\theta)$$22where $\theta$ is **everything learnable** — weights, biases, *and even the word vectors*. 連詞向量也一起學。23So the whole game is: **how do we compute $\nabla_\theta J$?** Two ways — (1) **by hand** (§2–3), (2)24**algorithmically = backprop** (§4). 兩條路:手算、或 backprop。2526*(Running example 貫穿例子: the [[04-neural-nets-ner]] window classifier — score $s=u^\top h$, $h=f(Wx+b)$,27$x$ = concatenated window word vectors.)*2829## 2. Gradients by hand — matrix calculus 手算梯度:矩陣微積分3031> "Multivariable calculus is just single-variable calculus **if you use matrices**." 用矩陣,多變數就跟單變數一樣。3233### 2.1 Gradient & Jacobian 梯度與 Jacobian34- **1 output, $n$ inputs** → gradient = a **vector** of partials $\big[\frac{\partial f}{\partial x_1},\dots\big]$.35- **$m$ outputs, $n$ inputs** → **Jacobian** = an $m\times n$ matrix, $\big(\frac{\partial f}{\partial x}\big)_{ij}=\frac{\partial f_i}{\partial x_j}$. 一堆偏導排成矩陣。3637### 2.2 Chain rule = multiply Jacobians 連鎖律 = Jacobian 相乘38For composed functions, **multiply** the Jacobians (order matters). 複合函數把 Jacobian 乘起來。 e.g. for39$h=f(z),\ z=Wx+b$: $\dfrac{\partial h}{\partial x}=\dfrac{\partial h}{\partial z}\dfrac{\partial z}{\partial x}$.4041### 2.3 Key Jacobians to know 幾個要記的 Jacobian42| Function | Jacobian |43|---|---|44| **element-wise** $h=f(z)$ | $\operatorname{diag}\!\big(f'(z)\big)$ — a diagonal matrix; in practice just an element-wise $\odot f'(z)$. 對角矩陣。|45| $z=Wx+b$, w.r.t. $x$ | $W$ |46| $z=Wx+b$, w.r.t. $b$ | $I$ (identity) |47| $s=u^\top h$, w.r.t. $h$ | $u^\top$ |4849($\odot$ = Hadamard / element-wise product. 逐元素相乘。)5051## 3. Gradients of the neural net (the error signal δ) 神經網路的梯度5253**The recipe 三步驟**: ① break the equations into simple pieces (track every shape!); ② apply the chain54rule; ③ write out the Jacobians. 拆式子(盯 shape)→ 連鎖律 → 寫 Jacobian。5556### 3.1 The error signal δ — re-use computation 誤差訊號 δ57Computing $\partial s/\partial W$ and $\partial s/\partial b$ **share the same prefix** of the chain. Give58that shared upstream part a name — the **error signal / upstream gradient**:59$$\boldsymbol{\delta}=\frac{\partial s}{\partial z}=\underbrace{u^\top}_{\partial s/\partial h}\odot\underbrace{f'(z)}_{\partial h/\partial z}$$60Compute $\delta$ **once**, reuse it — that reuse is the whole idea of backprop. 算一次 δ 重複用,正是 backprop 精神。6162### 3.2 Derivative w.r.t. a matrix + the shape convention 對矩陣微分 + shape 慣例63Pure math would make $\partial s/\partial W$ a $1\times nm$ Jacobian — awkward for SGD. So we use the64**shape convention**: **the gradient has the same shape as the parameter**. 梯度形狀 = 參數形狀。65$$\frac{\partial s}{\partial W}=\boldsymbol{\delta}\,x^\top\quad(n\times m,\ \text{an **outer product**}),\qquad66\frac{\partial s}{\partial b}=\boldsymbol{\delta}$$67- **Why the transpose / outer product** 為何是外積: each input feeds each output → $\delta$ (error at the68  output $z$) times $x$ (local input) gives every $W_{ij}$ contribution. 每個輸入接每個輸出 → 外積。69- **Sanity trick** 對照維度: if shapes don't match, transpose/reorder until they do — $\delta$ arriving at a70  layer has the **same shape as that layer**. δ 的形狀跟該層一樣,對不上就轉置。7172## 4. ⭐ Backpropagation 反向傳播7374Backprop = **the chain rule applied along a computation graph, reusing shared sub-derivatives**. 就是在75計算圖上套連鎖律、並重複利用共享的偏導。7677### 4.1 Computation graph + forward pass 計算圖 + 前向78Software writes the net as a **graph**: source nodes = inputs, interior nodes = operations, edges pass79results. Running it left-to-right = **forward propagation** (save the intermediate values!). 前向:算出每個80節點的值並**存起來**。8182### 4.2 Single node: the one rule 單一節點:唯一規則83Each node has a **local gradient** (output w.r.t. its input). Given the **upstream gradient**:84$$\boxed{[\text{downstream}] = [\text{upstream}] \times [\text{local}]}$$85下游梯度 = 上游梯度 × 本地梯度。 Multiple inputs → one downstream per input (each with its own local gradient).8687### 4.3 Node intuitions 節點直覺 (+ · max · ×)88- **`+` distributes** 分配: copies the upstream gradient to **each** summand unchanged. 加法把梯度原封複製給每個加數。89- **`max` routes** 路由: sends the whole upstream gradient to the **arg-max** input, `0` to the others. 只給最大的那條。90- **`×` switches** 交換: each input's downstream = upstream × **the other** input's value. 乘法把梯度乘上「另一個輸入」。9192### 4.4 Two efficiency rules 兩個效率要點93- **Gradients sum at outward branches** 分岔處相加: if a value is used in several places, **add** the94  gradients coming back from all of them. 一個值被用在多處 → 回傳的梯度相加。95- **Compute all gradients at once** (don't recompute shared prefixes) — exactly why we cached $\delta$. 一次算完,別重算。9697### 4.5 The general algorithm 通用演算法981. **Fprop**: visit nodes in **topological order**, compute each from its predecessors (save values). 拓樸序前向。992. **Bprop**: initialize output gradient $=1$, visit nodes in **reverse order**, apply100   `downstream = upstream × local` (summing over successors). 反序、輸出梯度設 1、往回套規則。101102Done right, **fprop and bprop have the same big-O cost**. 兩者複雜度同級。103104## 5. In practice: autodiff & gradient checking 實務105106- **Automatic differentiation** 自動微分: PyTorch/TensorFlow build the graph and do bprop for you — you107  only hand-write each node's **forward** and **local gradient**. 框架自動,你只寫節點的 forward + local grad。108- **Numeric gradient check** 數值梯度檢查 (for debugging a layer): $\frac{\partial J}{\partial\theta}\approx109  \frac{J(\theta+h)-J(\theta-h)}{2h}$ with $h\approx10^{-4}$. Correct but **slow** (recompute per parameter);110  use it only to verify an implementation. 準但慢,只拿來驗證。111- **Why learn this** 為何要懂: frameworks do it for you, but backprop **doesn't always work out of the box**112  — knowing the internals is key to debugging (e.g. **exploding / vanishing gradients**, a later lecture).113  懂內部才好 debug(梯度爆炸/消失)。114115## 6. One-line summary 一句話總結116117> **Training = SGD, which needs $\nabla_\theta J$.** Compute it with the **chain rule**; **backprop** does118> this efficiently on the computation graph via one rule — **downstream = upstream × local** — caching the119> shared **error signal δ** and summing gradients at branches. Forward saves values, backward applies the120> chain rule. 訓練靠 SGD 要梯度;backprop 用「下游=上游×本地」在計算圖上有效率地套連鎖律,快取 δ、分岔相加。
